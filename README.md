#  HomeBuddy

**HomeBuddy** is a full-stack web application that connects families with trusted domestic workers such as maids, cooks, babysitters, drivers, elder care providers, and event helpers.

The platform helps users easily find workers based on their location and service requirements while providing workers with a dedicated platform to receive genuine job opportunities.

#  How HomeBuddy Works

##  For Users

1. Sign up or log in.
2. Create a user profile.
3. Browse available workers.
4. View worker details.
5. Send a hiring request.
6. Track the request status.
7. Contact the worker once the request is accepted.

---

##  For Workers

1. Sign up or log in.
2. Create a professional profile.
3. Add services, experience, location, and expected salary.
4. Receive hiring requests from users.
5. Accept or reject requests.
6. Connect with users after accepting the request.
